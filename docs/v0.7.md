# BinX v0.7 — Symbols & Debug Information

## Goal

v0.7 connects the binary formats parsed by BinX with the symbols and debug metadata developers need when investigating real executables.

## Symbols

`binx symbols <file>` extracts a normalized symbol list.

Supported sources:

- ELF `.symtab` / `.dynsym` symbols already parsed by the ELF analyzer.
- PE exports.
- PE imports.
- PE CodeView records as debug-symbol identity records.

Each normalized record contains a name, kind, address, size where available, source, external/weak status, and module where applicable.

## Debug information

`binx debug <file>` (also `debug-info`) reports available debug metadata.

### ELF / DWARF

BinX discovers `.debug_*` sections and reports their presence. `.debug_info` compilation-unit headers are counted with a bounded parser for DWARF v2-v5 32-bit unit lengths. This provides a safe inventory without attempting to evaluate DWARF expressions or execute debug information.

### PE / PDB

BinX parses CodeView RSDS records from PE debug directories and reports the PDB path, GUID and age. This identity is useful for locating a matching PDB manually. v0.7 deliberately does not contact Microsoft symbol servers or download PDB files.

## JSON

Symbols and debug output use schema version 5. The schema is intended to be stable enough for scripts while keeping format-specific details explicit.

## Safety

All analysis is performed on the file bytes. BinX does not execute the target, load DLLs, contact symbol servers, or download external debug data.

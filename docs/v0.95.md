# BinX v0.95 — Unified Analysis & Reporting

v0.95 sits between the v0.9 crash-analysis release and the v1.0 local toolkit. It adds one compact report command that combines the existing BinX analysis engines without executing or modifying the input.

## Commands

    binx report app.exe
    binx report app.exe --json
    binx analyze app.exe --json

`analyze` is an alias for `report`.

## Report contents

- file name and size
- detected binary format, architecture, endianness and platform
- direct dependency names
- symbol count
- DWARF/PDB presence and compilation-unit count
- code, initialized-data and uninitialized-data size totals
- a small ASCII string sample

The report intentionally summarizes existing analyzers instead of duplicating their full output. Use `inspect`, `symbols`, `debug`, `deps`, `strings`, `size`, `hash`, `diff`, and `crash` for detailed views.

## JSON

The unified report uses schema version 5 and is designed for scripts and CI consumers.

## Design constraints

The report is deterministic, local-only, and bounded. String sampling is capped at ten entries, and it does not recursively resolve dependencies or contact external symbol services.

# BinX v0.1.0

## Purpose

v0.1 is the foundation release for BinX. It creates the binary-loading, format-detection, metadata, hashing, CLI and testing layers that later analysis features build on.

## Supported metadata

### PE

PE32 and PE32+:
- DOS/PE signature validation
- machine
- section count
- timestamp
- optional-header magic
- entry-point RVA
- entry-point virtual address
- image base
- image size
- headers size
- subsystem
- basic architecture mapping

### ELF

ELF32 and ELF64:
- class
- byte order
- machine
- entry point
- section count
- basic architecture mapping

### Mach-O

- 32-bit thin detection
- 64-bit thin detection
- fat/fat64 detection
- byte order
- basic CPU architecture mapping for thin binaries

## Safety model

Binary input is treated as untrusted data. Parsers validate file bounds, offsets, sizes, header lengths and arithmetic before dereferencing. The program never executes, loads or invokes code from the inspected file.

## CLI contract

Exit codes:
- 0 success
- 1 general failure
- 2 invalid arguments
- 3 input file not found
- 4 file access/output failure
- 5 invalid binary
- 6 unsupported format
- 7 analysis failure

JSON is intended for scripts and CI and is a machine-readable interface from v0.1 onward.

## Non-goals

v0.1 does not implement disassembly, symbols/PDB/DWARF, dependency resolution, binary diff, crash dump parsing, cloud APIs, telemetry or web UI.
